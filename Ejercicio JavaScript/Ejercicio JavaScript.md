# Ejercicio ***JavaScript***

## **Introduccion**
  JavaScript es un lenguaje de programación que hace que los sitios web sean interactivos y dinámicos. JavaScript permite a los desarrolladores implementar lógica y hacer que las aplicaciones respondan a las acciones del usuario. JavaScript es orientado a objetos, flexible y funciona bien tanto para scripts pequeños como para proyectos más grandes. Hoy en día, JavaScript es el único lenguaje que todos los principales navegadores entienden de forma nativa, lo que lo hace esencial para el desarrollo web moderno.

## **Síntesis**
  JavaScript surgió a mediados de los años 90, cuando las conexiones a internet eran lentas y las interacciones del lado del servidor eran poco eficientes. Y en 1995, Brendan Eich creó LiveScript para Netscape Navigator 2.0. Poco después, Netscape se asoció con Sun Microsystems y renombró el lenguaje como JavaScript. Luego, Microsoft lanzó JScript, una copia cercana de JavaScript. Para 1997, Netscape presentó JavaScript a ECMA para su estandarización, dando lugar a ECMAScript, la especificación oficial que sigue evolucionando hoy en día.
  En 1996, ECMA formó el comité TC39 para asegurarse de que JavaScript fuera multiplataforma e independiente de cualquier empresa. El primer estándar fue ECMA‑262, siendo la versión 1.3 la primera implementación de ECMAScript. Las versiones posteriores 2, 3, 5 y 6 ampliaron el lenguaje, y ECMAScript 2016 es la más reciente. Hoy en día, JavaScript está estandarizado a nivel global y es compatible con todos los navegadores, convirtiéndolo en la columna vertebral de las aplicaciones web interactivas.
  Las características de JavaScript incluyen actualizaciones dinámicas de contenido, control de multimedia y animaciones. Los fundamentos de la programación incluyen variables como (var, let, const), condicionales (if-else y switch), operadores lógicos (and, or, not) y bucles (for, while, do-while). Las clases ofrecen una sintaxis más clara para los objetos. Eventos como onclick, onmouseover y onload conectan las acciones del usuario con interfaces interactivas.
  ## **Reflection**
   Lo más útil de JavaScript es cómo cambia un sitio web de ser estático con imágenes y texto a algo interactivo. Añade cosas como botones que activan acciones, formularios que verifican la información antes de enviarla o animaciones que hacen la página más atractiva. Creo que esto hace que aprender JavaScript sea más interesante porque realmente puedes ver los resultados de tu código. Pasa de ser una página web que se ve bien a una que también hace algo útil.
  ## **Conclusion**
 JavaScript ha crecido mucho desde que se creó por primera vez, y hoy en día es uno de los lenguajes más utilizados. Con JavaScript, las páginas web pasaron de solo mostrar información a realmente responder a los usuarios. Ayuda a construir un sitio web más completo y atractivo. Por eso JavaScript sigue siendo una parte clave del desarrollo web.
